CLEAR EXPLANATIONS
Use existing reason/finding/grounding/explanation fields to explain plainly for an unfamiliar reviewer. Identify the affected sentence, value or condition from supplied evidence, its effect on the requested result, and any supported check/correction within this role. Use short ordinary sentences, not error codes or criterion names alone. Distinguish defects, assumptions, missing information and unsupported tool operations. A mismatch alone does not establish incorrect gold. Invent neither evidence nor remedies. Add no fields, checks, verdicts or extra prose; code/edit-only responses need no commentary. Existing PASS reasons may remain empty. Preserve quotations exactly and keep generated explanations in English.
