HTML 다운로드
판정 기준 · 저장 안내

Accept는 현재 역산 판정(true 또는 false)에 동의, Reject는 비동의, Pending은 보류입니다. 미확인은 별도로 구분합니다. Reject·Pending에만 댓글을 입력합니다. Reject·Pending을 선택하면 해당 댓글 입력창으로 바로 이동합니다. ER-2의 Accept를 저장하면 필터에 표시된 다음 문제로 이동하고 왼쪽 ER-1을 선택합니다. 두 열은 같은 ID의 독립적인 입력 근거 제거 조건이며, ER-2가 ER-1에 이어서 삭제한 결과를 뜻하지 않습니다.

분홍 취소선은 ER-1, 보라 취소선은 ER-2의 제거 대상이 원본에 있던 위치입니다. 원본 표시와 실제 남은 Q/C는 구분되어 있습니다. 표시를 위해 추가한 원본은 기존 역산 판정을 다시 계산하는 데 사용하지 않습니다.

이름별 브라우저 자동 저장, 중간 저장 JSON, JSON Import, 진행 포함 HTML 저장을 사용합니다. 같은 이름의 더 최근 기록은 유지합니다. 단일 HTML Export는 전체 문항·이름·판정·댓글·진행 위치를 한 파일에 담습니다. Export 후 표시되는 다운로드 링크로도 파일을 받을 수 있습니다. 이전 화면에서 저장한 JSON도 Import할 수 있습니다. 필터는 열별 true/false를 함께 만족하는 ID를 표시하며, Export에는 전체 데이터가 들어 있습니다.

한국어는 표시 번역입니다. 영어 원문도 함께 대조해 주세요. false는 완전한 역산 불가능 증명이 아닙니다.
