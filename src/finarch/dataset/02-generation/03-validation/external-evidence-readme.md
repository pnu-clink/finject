# 외부 근거

원문 숫자는 `03-program.json`의 facts에 보관하고, 외부 규칙·표는 `external-evidence.json`에 출처·위치·조건·선택값·적용 설명과 함께 보관합니다.

POT 응답의 외부 근거 선언 → 검토된 카탈로그 대조 → 이 파일 저장 → Python 실행 → 그래프 순서입니다. 모델이 쓴 출처만으로 검증 완료로 인정하지 않으며, 미등록 근거는 실행 전에 중단합니다.

`SOURCE_VERIFIED`는 출처와 표 값을 확인했다는 뜻입니다. 해당 문항에 모든 조건이 명시됐다는 뜻이 아니므로 `application_status`는 사람 검토에서 확인합니다. 원문에 없는 가정을 원문 조건으로 바꾸지 않습니다.

공통 뷰어의 03 계산과 정답 및 04 계산 그래프에서 외부 근거를 확인합니다. 그래프의 `evidence` 연산은 원문 입력을 받아 표의 행을 선택합니다. 등록되지 않은 선택값으로 변형되면 임의 비율을 만들지 않고 중단합니다.
