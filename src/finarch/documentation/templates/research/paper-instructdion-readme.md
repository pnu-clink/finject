# 논문 작성 지침 기록

이 README는 문서 템플릿에서 생성합니다. 사용자가 지정한 경로 `paper/instructdion`을 사용합니다.

## 읽는 순서

1. [작성 원칙](WRITING-GUIDELINES.md): 사용자 문체 지시, 주장 범위, FInject 용어, 공식 자료.
2. [2026-10-03 영문 원고 리뷰](reviews/20261003-english-manuscript-review.md): 우선 수정 사항, 절별 영문 제안, 표·그림·제출 구성 검토. 리뷰 당시의 제안 기록입니다.
3. [리뷰 적용 기록](reviews/20261003-review-application.md): 한·영 Draft와 로컬 PDF에 적용한 내용 및 확인 대기 사항.
4. [변경 로그](events.jsonl): 기록한 요구와 변경 시점.
5. [한글 Draft 직접 편집](DRAFT-EDITOR.md): 편집기 사용과 원문 / Draft 저장 연결.

현재 수량과 검토·승인 순서는 [MANUSCRIPT-STATE.json](MANUSCRIPT-STATE.json)을 따릅니다. 1,551개는 human annotation 전 원본 수이며 상세 수량은 부록에 둡니다. [로컬 LaTeX 미리보기](../local-preview/README.md)는 검토용입니다. Revision Draft에서 확인하고 사용자가 결정한 뒤에만 Overleaf에 반영합니다.

후속 원고 수정 전에 작성 원칙을 확인합니다. 사용자 지시와 공식 제출 규정을 구분하며, 원고의 우수성이나 심사 결과를 보장하는 표현을 쓰지 않습니다.

[공통 연구 뷰어](http://127.0.0.1:8896/viewer/research/)의 **2026-10-03 · 3장 재구성 · 제작·평가와 상세 부록** 자료 하단에도 이 기록으로 연결되는 링크가 있습니다.

영문 원고 리뷰는 같은 뷰어의 **2026-10-03 · 영문 원고 리뷰 · 주장·문체·표·그림**에서 읽습니다. 검토 자료의 해시와 작업 로그는 [리뷰 실행 안내](../../reports/run/20261003-english-manuscript-review/README.md)에 연결했습니다.
