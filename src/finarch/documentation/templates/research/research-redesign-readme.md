# 원논문에서 현재 연구로: 개선 방향과 실험 비교

2026-09-26 · 회의록과 현행 문서를 대조한 내부 검토 자료입니다. 현재 논문 본문과 실험 설정은 변경하지 않았습니다.

## 읽는 순서

[본문](RESEARCH-DIRECTION.md)의 1–3절에서 연구 목적·회의 흐름·관련 연구와의 차이를, 4절에서 생성 방법을 읽으시면 됩니다. 5–7절은 원논문 대비 실험과 보완안, 8절은 유지·변경·추가 판단표, 9절은 논문에 사용할 서술 초안입니다. 10절은 근거 범위입니다.

[공통 연구 뷰어](http://127.0.0.1:8896/viewer/research/)에서 ‘원논문 → 현재 연구 · 개선 방향과 실험 비교’를 선택하시면 실제 저장 문서를 읽습니다. 별도 결과 폴더 HTML은 만들지 않았습니다.

## 파일 역할

|파일|역할|
|---|---|
|RESEARCH-DIRECTION.md|본문과 비교표·우선순위·서술 초안|
|sources.json|회의록·원고·현행 문서의 경로와 해시, 공개 문헌 URL|
|verification.json|문서 구조·뷰어 제공·현재 원고 보존 확인|
|events.jsonl|작성·검토 기록|

기존 원고는 연구 경위 파악용이며 새 논문의 인용 근거로 추가하지 않습니다. ‘채택·추가 권고’는 연구 제안이며 실행 승인이나 실험 완료가 아닙니다. 새 모델 호출과 실험은 수행하지 않았습니다. 이 README는 src/finarch/documentation/templates/research/research-redesign-readme.md에서 생성합니다.
