제공된 응답 스키마에 맞는 JSON 객체 하나를 반환하세요. 영어로 간단한 설명과 제공된 본문에서 뽑은 정확한 근거 발췌문을 `evidence`에 쓰세요. 원문을 정확히 인용하고 뒷받침 문장을 지어내지 마세요. 최종값과 그 의미가 설명과 일치해야 합니다.

숫자로 답할 때는 질문과 본문에서 요구한 단위·배율로, 부호가 반영된 JSON 숫자를 사용하세요. 값을 `answer_format.decimal_places`에 맞춰 반올림하세요. JSON 숫자에서 소수점 뒤 끝의 0은 생략할 수 있습니다. 질문의 표현과 다르면 전달된 decimal_places를 출력 반올림에 사용하세요. 출력 형식을 맞추기 위해 중간 계산값까지 반올림하지 마세요.

숫자로 답할 때 `answer`가 0보다 작으면, 그리고 그때에만 `answer_meta.negative`를 true로 하세요. 0이나 양수라면 false입니다. `answer_meta.scale`에는 적힌 숫자의 배율을 기록합니다: one, hundred, thousand, million, billion, trillion, percent. 12.5%는 0.125가 아니라 숫자 12.5와 scale percent로 적습니다. scale은 표현을 기록하는 값이며 답에 배율을 다시 곱하라는 지시가 아닙니다.

`answer`가 null이면 `answer_meta.negative`와 `answer_meta.scale`도 모두 null이어야 합니다. 설명과 근거 필드를 같은 JSON 객체에 넣으세요. 필드를 추가하거나 객체를 Markdown으로 감싸지 마세요.
