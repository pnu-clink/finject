# {run_id} · 실행 결과

[첫 문항의 실제 파일 목록](test-0001/README.md) · [뷰어](http://127.0.0.1:8893/?run={run_id}&case=test-0001&tab=dtt) · [통합 로그 뷰어](http://127.0.0.1:8893/logs?run={run_id})

준비된 원문 중 실행 대상으로 지정된 문항을 입력으로 계산 코드 → 계산 → 그래프 → 변경 계획 → 변형 문장 생성 → 의미 검사 → 사람 검토 자료 순서로 실행합니다. 대상 수와 문항별 상태는 summary.json에서 확인합니다. 기존 런의 결과를 사용하지 않습니다. 모델은 Luna, 추론 없음입니다. 앞·뒤 쌍은 이번 실행에서 생성한 문장 하나를 위치만 바꿉니다. IC-SOURCE Type 1은 검증된 IC-VALUE 앞 본문의 원래 주장에, Type 2는 검증된 IC-VALUE 뒤 본문의 추가 주장에 출처만 붙입니다. 생성할 수 없는 조건과 실패는 별도 사유로 기록합니다.

결과와 로그는 같은 문항·단계·하위 처리 번호를 씁니다. 단계별 파일은 문항 README, 실제 시간순은 `log/run/{run_id}/default.log`에서 확인합니다. 기록의 파일 경로와 상태를 직접 확인하며 모델 합의를 사람 승인으로 해석하지 않습니다.
