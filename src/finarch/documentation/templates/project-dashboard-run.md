# 프로젝트 현황 대시보드 · 2026-09-29

이 폴더는 프로젝트 현황 화면의 제작·확인 기록입니다. 모델 호출이나 새 대상 모델 실험은 수행하지 않았습니다.

1. [events.jsonl](events.jsonl): 만든 파일, 확인 작업과 시각을 순서대로 기록한 로그입니다.
2. [verification.json](verification.json): 저장 자료에서 읽은 범위, API·화면 검사 결과와 한계를 기록합니다.
3. [프로젝트 현황 화면](http://127.0.0.1:8895/dashboard/03-project/): `reports/run`과 로컬 Codex 기록을 현재 시점에 다시 읽어 결과를 보여줍니다.
4. [자료·코드 흐름](../../../docs/03-dashboard/README.md): 어떤 파일이 무엇을 읽는지 확인합니다.

화면에서 먼저 범위와 갱신 시각을 보신 뒤 미완료 항목의 `근거 열기`로 원본 문서·상태 파일을 확인합니다. 업무별 묶음은 화면 분류이며 실제 부모·자식 관계와 다릅니다. 세션별 최근 요청은 작업 완료 판정이 아닙니다. 로컬에 없는 다른 호스트 세션과 아직 기록되지 않은 일은 이 화면에 나타나지 않을 수 있습니다.
