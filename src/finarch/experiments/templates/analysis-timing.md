## 읽는 순서와 해석

1. 이 문서에서 단계별 시간을 확인합니다. 표에는 상위 단계와 내부 처리가 함께 있어 행 전체를 합산하면 안 됩니다.
2. [timing.json](timing.json)은 동일한 집계와 진행 중인 처리, 중앙값·95백분위·최댓값을 담습니다. 뷰어는 이 파일을 읽습니다.
3. [timing-events.jsonl](timing-events.jsonl)은 각 처리의 시작·종료 시각, 단조 시계로 측정한 경과 시간, 실패·재시도 시도를 보존합니다.
4. 개별 모델 호출의 원응답과 기존 `process.json`은 각 단계의 `calls`에서 확인합니다. [공통 로그](../events.jsonl)는 실행 순서를 기록합니다.

동시에 진행한 호출 시간은 겹치는 구간을 한 번만 세어 경과 시간을 구합니다. 호출별 시간의 합은 자원 사용 지표이며 전체 소요 시간과 다릅니다. 모델 호출 시간에는 CLI·네트워크·제공자 처리가 포함되어, 제공자 내부 대기와 추론 시간을 따로 확정할 수 없습니다. 종료 기록이 없는 중단은 미측정으로 남깁니다.

표는 측정된 실행 구간을 누적한 값입니다. 실행기를 종료한 뒤 보정·재개하기까지의 공백은 포함하지 않습니다. 종료 횟수와 중앙값에는 거절·실패로 끝난 시도도 포함되므로 유효 응답만의 처리 속도로 해석하지 않습니다.

기존 Evaluation 수집은 Analysis 시간과 구분합니다. 시간 기록을 연결하기 전 수집 시간과 코드 정리 시간은 측정에 포함되지 않습니다. 이 안내는 `src/finarch/experiments/templates/analysis-timing.md`에서 자동 생성합니다.
