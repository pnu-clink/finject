# 연구 발견 주제별 통합 · {run}

저장된 A03 연구 발견 {count}개를 주제별로 묶고 논문 v{version}의 RQ1·RQ2·SQ1–SQ6에 연결한 편집 색인입니다. 새 모델 호출, 새 의미 판정, 확정된 논문 결론이 아닙니다.

1. [실험 뷰어](http://127.0.0.1:8894/?run={run}&tab=reports)의 **연구 해석** 화면에서 RQ/SQ별 주제 묶음을 펼쳐 읽습니다.
2. [rq-review.md](rq-review.md)는 각 주제의 주장·근거·다른 설명·한계를, [rq-review-audit.md](rq-review-audit.md)는 모든 원본 F의 주 그룹과 보조 그룹을 보여 줍니다.
3. [rq-sq-review.json](rq-sq-review.json)은 뷰어용 질문 색인, [rq-review.json](rq-review.json)은 그룹 배정과 출처 해시, [rq-review-validation.json](rq-review-validation.json)은 전체 대응 검사를 기록합니다.
4. [findings.json](findings.json)·[findings.md](findings.md)에서 원본 F와 관찰 ID를 확인한 뒤 인용된 Evaluation 원응답까지 따라갑니다. 기존 원응답·점수·프롬프트는 수정하지 않았습니다.

SQ2·SQ4·SQ5는 이 발견 묶음의 직접 검토가 없고, SQ6은 독립 반복 확인 전까지 보류합니다. 각 그룹의 F 수는 독립 실험·독립 문항 수가 아닙니다.
