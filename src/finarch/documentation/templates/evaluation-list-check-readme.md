# 평가자 HTML · 전체 목록과 필터 수량

`evaluation/workspace.js`에서 160문항씩 잘라 표시하던 목록을 전체 표시로 변경했습니다. 검색창 아래 수량은 실제 화면에 있는 문항 수입니다. 현재 선택 문항이 필터 밖에서 유지되는 경우 필터 일치 수를 따로 표시합니다. 앞/다음 목록 버튼 없이 목록 영역을 스크롤합니다.

1. `validation.json`, `terminal.log`: 실제 검사 범위·결과·원본과 수정본 해시.
2. `list-filter.png`: 필터 적용 수량과 전체 스크롤 목록의 실제 화면.
3. `before-workspace.js`, `before-style.css`, `before-i18n.js`: 변경 전 화면 코드.
4. `before-evaluation.html`: 기존 다운로드 HTML의 보관본.

다운로드 폴더의 `20261003-concat-001-평가 (1).html`에도 화면 코드만 적용합니다. 배포본 ID·내장 데이터·문항별 해시·Import 형식·판정은 보존합니다. 같은 HTML을 새로고침하면 새 목록이 나타나며 기존 Import JSON을 그대로 사용합니다. 다음 Export부터도 같은 목록을 사용합니다.

실제 수정 HTML을 별도 로컬 주소에서 열고 김진수 Import 7,000판정을 적용했습니다. 미평가 260/1,260문항, 전체 1,260문항, 검색 1문항, 목록 넘김 버튼 0개와 목록 내부 스크롤을 확인했습니다. 화면은 `list-filter.png`에 보관했습니다.

코드 검사는 필터·검색·유형·미평가·현재 선택 유지와 160건 초과 목록을 포함합니다. 제작 데이터 의미 평가나 LLM 호출은 아닙니다.
