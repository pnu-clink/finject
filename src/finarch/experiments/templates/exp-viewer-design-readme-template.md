# exp-viewer

상태: **설계 단계 / 미구현**.

실험 결과 전용 뷰어입니다. 데이터 루트는 `reports/experiments-run`이며, 기존 제작 뷰어와 분리합니다. 실제 결과 폴더 통합과 문항별 calls 정리는 완료했습니다. [저장 구조](../docs/experiments-call-layout.md)를 참고하세요.

## 읽는 순서

1. [{design_label}]({design_path}): 확정 요구·화면 구성·데이터 연결·경로 통합·구현 순서.
2. [{log_label}]({log_path}): 확인한 자료와 설계 산출물 검증 기록.

현재 이 폴더에는 안내 문서만 있습니다. 화면·서버·HTML·JavaScript는 아직 구현하지 않았습니다. 이 README는 `src/finarch/experiments/templates/exp-viewer-design-readme-template.md`에서 생성했습니다.
