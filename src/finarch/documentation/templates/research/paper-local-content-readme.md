# 로컬 검토본 보충 문안

이 README는 문서 템플릿에서 생성합니다.

1. [counts-en.md](counts-en.md): human annotation 전 수량을 설명하는 영문 부록.
2. [counts-ko.md](counts-ko.md): 같은 내용의 한국어 대응본.
3. [현행 수치](../instructdion/MANUSCRIPT-STATE.json): 사용자 정정과 수량의 상태.

수정 후 프로젝트 루트에서 `python3 src/finarch/documentation/sync_paper_revision.py --build`를 실행하면 Revision Draft와 로컬 LaTeX에 반영합니다. 두 언어의 수량·의미를 함께 갱신해야 합니다. Overleaf로는 자동 반영하지 않습니다.
