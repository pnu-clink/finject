저장된 응답의 트래픽
기본 산점도는 한국 시각으로 표시한 실제 완료 시각과 응답 시간을 연결합니다. 실행 중인 실시간 요청이 아닌 저장된 기록입니다. 축을 바꾸면 응답 시간과 출력 토큰을 비교할 수 있습니다.
점 · 표 · 원문
점이나 표의 문항을 클릭하면 해당 응답의 질문·설명·인용과 Unguided Solving/Criteria-Guided Solving 대조를 볼 수 있습니다. 영역을 드래그하면 표 범위가 좁아집니다. 표는 키보드로도 선택할 수 있습니다.
요약 수치의 범위
전체 응답을 제외한 요약은 현재 필터 범위입니다. 영역 선택은 연결 표만 좁힙니다. p50/p95는 미관측 시간을 제외하고 원정밀도 값에 선형보간을 적용합니다.
관찰과 의미 판정
형식 통과는 의미 정답을 보장하지 않습니다. 숫자 없음(null), 필드 없음과 응답 미관측을 구분합니다. 자동 후보 태그는 검토할 대상을 표시하며 확정 오류가 아닙니다. 시간·출력 토큰으로 정확도나 반복 안정성을 판단하지 않습니다.
