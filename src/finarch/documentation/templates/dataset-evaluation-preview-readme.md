# 평가자용 HTML 확인

이 README는 `src/finarch/documentation/templates/dataset-evaluation-preview-readme.md`에서 생성합니다.

1. [사용 방법·파일 책임·흐름](../../docs/01-dataset/90-operations/04-viewer.md#평가자용-html-내보내기)을 먼저 읽습니다.
2. [확인 로그](validation.json)에서 생성 문항·자동 검사·브라우저 확인 범위를 읽습니다.
3. [평가 화면](evaluation-sample.html)을 엽니다. 20260917-002와 003의 각각 test-0001·test-0002를 담은 네 문항 확인본이며 전체 실행 배포본이 아닙니다.

|파일|역할|
|---|---|
|`evaluation-sample.html`|평가 화면과 해당 문제·유형의 원본 보기를 포함한 단일 HTML|
|`validation.json`|실제 자료·자동 검사·브라우저 확인 범위와 미확인 항목|
|[workspace-checks.json](workspace-checks.json)|문제/유형 이동, 판정·주석, 원본 복귀와 키보드 검사|
|[export-state-checks.log](export-state-checks.log)|저장 파일 형식·Import 검사·실행 분리·한 문항 압축 해제 검사|
|[evaluation-screen.jpg](evaluation-screen.jpg)|실제 브라우저의 확인 화면; 표시된 임시 판정은 데이터 품질 검증 결과가 아님|

이 화면은 왼쪽 유형·문제 목차와 판정 bullet, 원본/변경 수식과 값 대입, 변경 문장·원문 맥락과 계산 그래프, 하단 판정·주석을 한 화면에 제공합니다. 분석용 필터·차수 안내·키보드 도움말은 표시하지 않습니다. 원문 전체 보기와 크게 보기에서 세부 근거를 확인합니다. 그래프는 기존 모양·범례를 사용하고 사각형 카드를 덧붙이지 않으며, 저장된 변수 전달만 합친 A/B 비교입니다. 계산값을 재실행하거나 누락 값을 0으로 바꾸지 않습니다.

질문은 굵고 큰 Q 다음에 표시합니다. **원본 보기**는 현재 문제·유형의 기존 제작 상세 화면을 같은 HTML 안에서 엽니다. 단계별 수식·Python·전체 그래프·검사 기록을 확인하고 **평가 화면으로 돌아가기**로 원래 평가 항목에 복귀합니다. 주석·판정은 유지하며 원본 보기에서는 판정을 수정하지 않습니다. 별도 서버·외부 파일을 요구하지 않습니다.

평가자 이름 → 숫자패드 1 통과 / 2 실패 / 3 유보 → 자동으로 다음 미평가 이동 → 임시 저장 또는 결과 Export 순으로 사용합니다. 체크를 끄면 현재 항목을 유지합니다. ←/→는 현재 판정·검색 필터에 맞는 항목으로 이동하며, 전체 필터에서 이전 판정을 수정할 수 있습니다. N으로 주석을 입력합니다. Enter는 주석 저장·입력 종료, Shift+Enter는 줄바꿈입니다. 주석은 선택입니다. 브라우저 임시 기록과 JSON은 Import에서 가져옵니다. 원본 제작 판정을 변경하지 않습니다.

**Q/E**는 판정 필터·검색에 맞는 문제 이전/다음, **A/D**는 같은 문제의 유형 이전/다음입니다. **v / Shift+V**는 현재 필터·검색 안의 다음/이전 저장된 유보·실패 항목으로 이동합니다. 이동은 원본 보기에서도 동작하며 입력 중에는 제외합니다. 그래프는 처음 표시와 창 크기 변경 시 전체 맞춤합니다.

실제 배포본은 [공통 제작 뷰어](../../viewer/dataset/index.html)의 **평가자용 HTML Export**에서 실행·표시 문항을 선택해 생성합니다. HTML 하나로 평가하며 `{평가자}-{실행}-MMDD.json`으로 결과를 전달합니다. 이 폴더의 검증용 판정과 화면 캡처는 실제 데이터 품질 평가 결과가 아닙니다. LLM 호출과 제작 데이터 변경은 없습니다.
