EXPERIMENT / HTML EXPORT

회차를 단일 HTML로 저장

선택한 회차의 모든 문항·조건·모델 응답과 원기록, 보고서를 하나의 HTML 파일에 담습니다. 현재 필터 밖의 자료도 포함합니다.

파일을 열면 서버 없이 여덟 화면과 필터를 사용할 수 있습니다. 분석자용 원문 정답도 포함하며, 자료는 내보낸 시점으로 고정됩니다.

비용·실행 화면의 이벤트는 뷰어와 동일하게 최근 저장 100개까지 포함합니다. 실행 폴더 밖의 제작 기준본은 포함하지 않습니다.
